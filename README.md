# Генератор приглашений

Свой локальный веб-генератор приглашений на праздник.
Оригинальный макет рисуется в браузере на Canvas — без чужих шаблонов и внешних сервисов генерации.

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес из терминала (обычно http://localhost:5173).

## Сборка

```bash
npm run build
npm run preview
```

Файлы для хостинга — в папке `dist/`.
